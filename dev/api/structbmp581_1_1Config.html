Detailed Description

Everything EnsureInitialized() and ApplyConfig() write to the chip.

The defaults are the reset values of the datasheet (section 7), so Config{} changes nothing on a freshly reset chip except that pressure is measured. Fields with a unit carry it as a suffix. Integral and enumeration members only: two configurations compare with ==.
