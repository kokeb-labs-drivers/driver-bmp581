# BMP581 Driver API reference {#mainpage}

The classes, types and registers of the BMP581 driver, generated from the headers in `inc/`.

Start with bmp581::BMP581, the driver, and bmp581::I2cInterface or bmp581::SpiInterface, the base of the port
you write. Errors are bmp581::Error inside bmp581::Result; the configuration is bmp581::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">BMP581 Driver
documentation</a>.
