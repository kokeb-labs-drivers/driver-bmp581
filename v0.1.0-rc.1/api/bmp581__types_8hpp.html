Detailed Description

Public types of the BMP581 driver: errors, Result<T>, configuration, measurements and the datasheet's timing and range constants.

Everything here is plain data with no platform dependency, so handlers, tests and tools can include it without the driver template. The configuration defaults are the chip's reset values (datasheet section 7), so Config{} describes a chip that was just reset, with one exception the driver always applies: pressure is measured (OSR_CONFIG.press_en = 1, see bmp581.hpp).

Section, table and figure numbers refer to the Bosch BMP581 datasheet, document BST-BMP581-DS004-13, revision 1.13.
