Detailed Description

template<typename Derived>
class bmp581::SpiInterface< Derived >

CRTP base of the platform SPI port.

Derive class MyPort : public bmp581::SpiInterface<MyPort> and implement the hooks in this file's description. The base declares no hook itself and no data; the driver checks your class with the SpiPort concept, so a missing or misdeclared hook is a compile error that names it.
